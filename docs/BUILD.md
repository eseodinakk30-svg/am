# Как получить APK

Собирать локально ничего не нужно — всё делает GitHub Actions.
Нужны только два секрета: почта и пароль аккаунта Unity.
Файл лицензии (`.alf` / `.ulf`) больше не требуется: Unity закрыла ручную
активацию Personal-лицензий, поэтому активация идёт напрямую через Unity Hub
по логину и паролю.

## Шаг 1. Добавить два секрета (один раз)

Открой:
`Settings → Secrets and variables → Actions → New repository secret`

Добавь два секрета:

| Имя | Значение |
| --- | --- |
| `UNITY_EMAIL` | почта аккаунта Unity (та, которой входишь на unity.com) |
| `UNITY_PASSWORD` | пароль этого аккаунта |

Аккаунт Unity бесплатный, регистрация — https://id.unity.com

> Пароль должен быть именно от Unity ID. Если ты входишь в Unity через
> Google, Facebook или Apple, отдельного пароля у аккаунта нет — его нужно
> сначала задать на https://id.unity.com в разделе Security.
>
> Если на аккаунте включена двухфакторная аутентификация, активация в CI
> не пройдёт. Двухфакторку нужно временно отключить в настройках Unity ID.
>
> При копировании пароля легко прихватить пробел или перевод строки —
> в секрете лишних символов быть не должно.

## Шаг 2. Быстрая проверка (~15 минут)

`Actions → «1. Быстрая проверка проекта» → Run workflow`

Она скачивает Unity, активирует лицензию и компилирует весь C#.
APK не собирается, поэтому проверка быстрая: если что-то не так с лицензией
или с кодом, узнаешь через четверть часа, а не через полтора.

Зелёная галочка — можно собирать APK.

## Шаг 3. Сборка APK (40–90 минут)

`Actions → «2. Сборка APK» → Run workflow`

Параметры:

* **architectures** — `both` (ARMv7 + ARM64, работает на любом Android)
  или `arm64` (только 64-битные телефоны, собирается примерно вдвое быстрее).
  Любой телефон, выпущенный после 2016 года, — ARM64.
* **release** — публиковать ли APK в Releases. Оставь включённым.

Готовый файл появится здесь:

* `Releases` — отдельным файлом, скачивается одним тапом с телефона;
* либо внизу страницы запуска, в разделе `Artifacts` (там zip).

APK подписан отладочным ключом Unity — для установки на свой телефон этого
достаточно. Для публикации в Google Play понадобится собственный keystore
и сборка AAB (`NebulaBuild.AndroidAab`).

## Установка на телефон

1. Скачай `.apk` из Releases.
2. Android спросит про установку из неизвестных источников — разреши.
3. Готово.

## Локальная сборка (если есть компьютер с Unity)

1. Unity Hub → Installs → Unity **2022.3.62f1**, модуль **Android Build Support**
   (вместе с Android SDK & NDK Tools и OpenJDK).
2. Unity Hub → Open → выбрать папку репозитория.
   Первый запуск дольше обычного: проект собирает все ассеты кодом,
   бинарных файлов в репозитории нет.
3. Меню `Nebula Nine → Build Android (APK)`.
   Файл появится в `Builds/NebulaNine.apk`.

Из командной строки:

```bash
Unity -batchmode -quit -nographics \
      -projectPath . \
      -executeMethod Nebula.EditorTools.NebulaBuild.AndroidApk \
      -logFile -
```

## Если сборка упала

Открой упавший запуск в `Actions`, разверни красный шаг — там текст ошибки.
Внизу страницы запуска лежат артефакты `unity-logs-*` с полным логом Unity.

Частые случаи:

| Сообщение | Что делать |
| --- | --- |
| `Нет секрета UNITY_EMAIL` | не добавлен секрет, см. шаг 1 |
| `Invalid Credential` / `code 143.002` | Unity ID отверг логин или пароль: опечатка, лишний пробел в секрете, вход через Google/Apple без своего пароля, либо включена двухфакторка |
| `error CS____` | ошибка компиляции C#; текст ошибки с номером строки — в логе |
| `No space left on device` | запусти сборку с `architectures: arm64` |
