# Unity APK: как собрать с телефона

Unity нельзя запустить без активированной лицензии — это требование Unity, обойти его
нечем. Но активация делается один раз и целиком в браузере телефона: ни компьютер,
ни установка Unity не нужны. Дальше APK собирается в облаке GitHub.

> **Где обычно застревают.** На сайте активации нужно выбрать **Unity Personal**.
> Если выбрать Plus или Pro — сайт попросит серийный код, которого у бесплатной
> лицензии не существует. Это единственная ловушка во всём процессе.

---

## Шаг 1. Аккаунт Unity

Если его ещё нет — зарегистрируйся на **id.unity.com** (бесплатно, только почта и пароль).
Эти же почта и пароль понадобятся дальше как секреты.

## Шаг 2. Запросить файл активации

1. Репозиторий → вкладка **Actions**.
2. Слева **«1. Unity: запросить лицензию»** → **Run workflow** → **Run workflow**.
3. Через ~1 минуту открой вкладку **Releases** — там появится релиз
   «Файл активации Unity» с прикреплённым файлом `.alf`.
4. Тапни по нему — он скачается **как обычный файл**, распаковывать ничего не надо.

## Шаг 3. Обменять `.alf` на лицензию `.ulf`

1. Открой **https://license.unity3d.com/manual**, войди в аккаунт Unity.
2. Загрузи скачанный `.alf`.
3. Выбери **Unity Personal Edition**, затем
   **«I don't use Unity in a professional capacity»**.
4. Скачается файл `.ulf` — это лицензия.

## Шаг 4. Три секрета

Репозиторий → **Settings** → **Secrets and variables** → **Actions** →
**New repository secret**. Нужны **все три**, иначе активация не пройдёт:

| Имя секрета | Значение |
|---|---|
| `UNITY_EMAIL` | почта аккаунта Unity |
| `UNITY_PASSWORD` | пароль аккаунта Unity |
| `UNITY_LICENSE` | **всё содержимое** файла `.ulf`, включая первую строку `<?xml …?>` |

`.ulf` — обычный XML. Открой его любым текстовым редактором или заметками,
выдели всё и скопируй.

**Если копировать XML с телефона неудобно** — есть обходной путь:
залей файл в репозиторий как `ci/unity.ulf`
(**Add file → Upload files**, выбрать файл, Commit). Сборка подхватит его сама,
секрет `UNITY_LICENSE` тогда не нужен.
Так стоит делать **только если репозиторий приватный**: файл содержит твой серийный
номер Unity. Публичный репозиторий — только через секреты.

## Шаг 5. Быстрая проверка (5–8 минут)

Actions → **«3. Быстрая проверка проекта»** → Run workflow.

Она компилирует весь C# и проверяет лицензию, но не собирает APK. Запусти её первой:
если что-то не так с лицензией или в коде есть опечатка, ты узнаешь через несколько
минут, а не через сорок.

## Шаг 6. Сборка APK (25–45 минут)

Actions → **«2. Сборка APK»** → Run workflow.

Готовый `NebulaNine.apk` появится:
* во вкладке **Releases** — качается одним тапом, это удобнее всего с телефона;
* и в блоке **Artifacts** внутри запуска.

## Шаг 7. Установка

Открой скачанный APK → Android попросит разрешить установку из неизвестных
источников для браузера или файлового менеджера → разреши → **Установить**.

APK подписан отладочным ключом Unity: для личной установки этого достаточно.
Для публикации в Google Play нужен свой keystore.

## Если что-то пошло не так

**«License activation strategy could not be determined».**
Не хватает секретов. Нужны именно три: `UNITY_EMAIL`, `UNITY_PASSWORD` и
`UNITY_LICENSE`. Первые два обязательны даже для бесплатной лицензии — GameCI
достаёт серийник из `.ulf`, но активирует его логином и паролем.

**Сайт просит серийный код.**
Выбран Plus или Pro. Вернись и выбери **Unity Personal Edition**.

**`Unity version … not found` / образ не скачался.**
GameCI публикует образы не для всех патч-версий. Запусти workflow ещё раз и укажи
другую версию ветки 2022.3 (список: game.ci/docs/docker/versions). Версия в поле
и в `ProjectSettings/ProjectVersion.txt` должна совпадать.

**Ошибки компиляции C#.**
Открой упавший шаг и скопируй строки с `error CS…` — в них указаны файл и строка.
Проект писался без доступа к компилятору Unity, так что первая проверка вполне может
что-то поймать; пришли текст ошибки, и я поправлю.

**Не хватило места на раннере.**
Workflow уже чистит лишнее. Если всё равно падает — оставь только ARM64,
убрав `AndroidArchitecture.ARMv7` в `Assets/Editor/NebulaProjectSetup.cs`.

## Альтернатива: Unity Build Automation

У Unity есть собственный облачный сборщик — **cloud.unity.com** → Build Automation.
Он подключается к GitHub-репозиторию и собирает APK, **не требуя файла лицензии**:
достаточно войти в аккаунт Unity. Бесплатный тариф существует, но лимиты по минутам
сборки Unity периодически меняет, и сколько именно даётся на Android — стоит смотреть
в самом сервисе. Если возня с `.ulf` не пошла, это второй рабочий путь.
