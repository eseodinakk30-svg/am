# Как получить APK с телефона

Собрать APK можно прямо в GitHub Actions — компьютер не нужен. Разово потребуется
активировать бесплатную лицензию Unity (без неё Unity не запускается даже в консоли).

Весь путь: **~5 минут твоих действий + 20–45 минут ожидания сборки.**

---

## Шаг 1. Запросить файл активации

1. Открой репозиторий → вкладка **Actions**.
2. Слева выбери **«1. Unity: запросить лицензию»** → кнопка **Run workflow** → **Run**.
3. Через ~1 минуту открой завершившийся запуск → блок **Artifacts** → скачай
   `Unity_Activation_File.zip` и распакуй. Внутри файл `Unity_v2022.3.62f1.alf`.

## Шаг 2. Обменять .alf на лицензию .ulf

1. Открой в браузере **https://license.unity3d.com/manual**
2. Войди в аккаунт Unity (или создай — бесплатно).
3. Загрузи файл `.alf` из шага 1.
4. Выбери **Unity Personal** → **«I don't use Unity in a professional capacity»**.
5. Скачается файл `Unity_v2022.x.ulf` — это и есть лицензия.

## Шаг 3. Положить лицензию в секреты репозитория

1. Открой `.ulf` как текст (это XML) и **скопируй всё содержимое целиком**.
2. Репозиторий → **Settings** → **Secrets and variables** → **Actions** →
   **New repository secret**.
3. Name: `UNITY_LICENSE`, Secret: вставь содержимое файла → **Add secret**.

## Шаг 4. Собрать APK

1. **Actions** → **«2. Сборка APK»** → **Run workflow** → **Run**.
2. Первая сборка идёт 25–45 минут (IL2CPP + скачивание образа Unity).
   Повторные — быстрее за счёт кэша.
3. Готовый файл появится в двух местах:
   * вкладка **Releases** репозитория — самый удобный способ скачать с телефона;
   * блок **Artifacts** внутри запуска.

## Шаг 5. Установить

Скачай `NebulaNine.apk` → открой → Android попросит разрешить установку из
неизвестных источников для браузера/файлового менеджера → разреши → Установить.

APK подписан отладочным ключом Unity: для личной установки этого достаточно,
для публикации в Google Play нужен свой keystore.

---

## Если что-то пошло не так

**`Unity version ... not found` / образ не скачался.**
GameCI публикует образы не для всех патч-версий. Запусти workflow ещё раз и в поле
`unityVersion` впиши другую версию ветки 2022.3 (например `2022.3.60f1`).
Список доступных: https://game.ci/docs/docker/versions — версию в поле и в
`ProjectSettings/ProjectVersion.txt` держи одинаковой.

**Ошибка лицензии.**
Проверь, что секрет называется ровно `UNITY_LICENSE` и содержит весь XML, включая
первую строку `<?xml ...?>` и закрывающий тег.

**Ошибка компиляции C#.**
Открой упавший шаг, скопируй строки с `error CS...` — по ним видно файл и строку.
Проект собирался без доступа к компилятору Unity, так что первая сборка вполне может
поймать опечатку в вызове API.

**Не хватило места на раннере.**
Workflow уже чистит лишнее перед сборкой; если всё равно падает — отключи ARMv7,
оставив только ARM64 (`PlayerSettings.Android.targetArchitectures` в
`Assets/Editor/NebulaProjectSetup.cs`).
