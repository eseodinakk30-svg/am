# AI NPC в Nebula Nine

Цель модуля — чтобы игрок ловил себя на мысли «я играю против людей». Поэтому AI
устроен не как набор состояний, а как **агент с ограниченным восприятием, несовершенной
памятью, характером и собственной моделью мира**.

Весь код — `Assets/Scripts/AI/`. Он не зависит от UI и сети, поэтому интеллект можно
улучшать отдельно от остальной игры.

---

## 1. Конвейер одного агента

```
TickFast (каждый кадр, все агенты)
    Perception.Sense      → новые записи в AgentMemory
    ExecuteGoal           → движение, работа у консоли, убийство, вент, починка

TickSlow (по очереди, несколько агентов за кадр)
    AgentMemory.Decay     → уверенность в старых наблюдениях падает
    SuspicionModel.Evaluate → пересчёт лог-шансов по всем уликам
    UpdateEmotion         → страх (экипаж) / «уровень тепла» (предатель)
    Planner.Plan          → выбор новой цели по утилитарной оценке

Собрание
    OnMeetingStart → ProposeSpeech ⇄ HearSpeech → DecideVote → OnMeetingEnd
```

`MatchManager.TickBrains` раздаёт бюджет: лёгкое восприятие — всем каждый кадр,
тяжёлое рассуждение — 1–5 агентам за кадр. 15 ботов укладываются в доли миллисекунды.

---

## 2. Личность (`AgentPersonality.cs`)

13 черт в диапазоне [0,1]:

`Intelligence, Memory, Observation, Logic, Caution, Courage, Trust, Deceit,
Aggression, Sociability, Persuasion, ContradictionSense, Strategy`

Черты не разыгрываются независимо — они берутся из **архетипа** плюс шум, поэтому
персонажи читаются как характеры, а не как случайные числа:

| Архетип | Поведение |
|---|---|
| Аналитик | осторожный, мало говорит, отлично рассуждает |
| Заводила | агрессивный, обвиняет мгновенно |
| Добряк | доверчивый, общительный, легко прощает |
| Следователь | собирает максимум улик, высокая логика и память |
| Манипулятор | лучший лжец и убеждатель |
| Параноик | подозревает почти всех |
| Конформист | идёт за большинством |
| Работяга | сфокусирован на заданиях, невнимателен |
| Ветеран | стратег, терпелив, его тяжело обмануть |
| Болтун | говорит без остановки, сигнал слабый |

Производные величины, которыми пользуется вся остальная система:

```
MemoryHalfLife   28…190 c      время полураспада уверенности
VisionScale      0.78…1.16     множитель дальности обзора
NoticeChance     0.55…0.995    шанс вообще заметить увиденное
EvidenceWeight   0.45…1.35     вес твёрдых улик
RumourWeight     0.9…0.18      вес чужих слов (у логика — низкий)
BandwagonBias    0.05…0.85     склонность голосовать «как все»
LieQuality       0.15…0.98     насколько правдоподобно врёт
MistakeChance    0.34…0.03     базовая вероятность ошибиться
```

**Сложность** (Easy → Master) сдвигает «навыковые» черты, но не обнуляет `MistakeChance`:
даже Master ошибается, его можно переиграть и обмануть.

## 3. Восприятие — единственная дверь в мир (`Perception.cs`)

Правило проекта: **события мира не попадают в память напрямую**. `PerceptionHub`
подписан на шину `GameEvents` и раздаёт события всем агентам, а каждый агент решает,
мог ли он это увидеть, через тот же вызов, что используется для рендера игрока:

```csharp
MatchManager.CanSee(observer, point, deck)   // дистанция + LOS по сетке + свет + вент
```

Что и как записывается:

| Событие | Условие | Сила |
|---|---|---|
| Другой игрок в поле зрения | LOS + `NoticeChance` | уверенность 0.65…1.0, ×0.68 при выключенном свете |
| Смена комнаты наблюдаемым | то же | средняя |
| «Он был со мной наедине» | видно ровно одного | 0.9 |
| Тело | LOS | высокая |
| Убийство | видно убийцу **и** жертву | твёрдая улика |
| Использование вентиляции | LOS до люка | твёрдая улика |
| Визуальное задание | LOS + задание действительно визуальное | сильное оправдание |
| Работа у консоли | LOS, шанс 0.35 | слабая (её подделывает предатель) |
| Саботаж | всем (сирена) | без указания виновника |

Роль игрока не передаётся никогда и ни при каких условиях — узнать её можно только
через улику. Камеры наблюдения дают записи с пониженной уверенностью (0.6),
админ-стол — только количество людей по отсекам, без имён.

## 4. Память (`AgentMemory.cs`)

Кольцевой буфер на 48…220 записей (зависит от черты `Memory`). Каждая запись:
вид, субъект, второй участник, комната, палуба, время, **уверенность**, доп. поле.

* Уверенность экспоненциально затухает с личным периодом полураспада.
* «Твёрдые» улики (убийство, вент, тело, изгнание, визуальное задание) затухают
  вдвое медленнее и не вытесняются при переполнении.
* Помимо перемещений хранится социальный слой: кто кого обвинял, кто кого защищал,
  кто за кого голосовал.

Запросы, которыми пользуется остальная система: «где, по-моему, был игрок X в момент T»,
«сколько времени X никто не видел», «был ли X со мной», «видел ли я визуальное
подтверждение», «сколько раз X обвинял».

## 5. Модель подозрений (`SuspicionModel.cs`)

Никакого «случайно выбрать подозреваемого». Для каждого игрока копятся **лог-шансы**,
вероятность = `sigmoid(logOdds)`. Априор берётся из доли предателей в живых и сдвигается
чертой `Trust` (параноик стартует выше, добряк ниже).

Основные вклады (умножаются на уверенность записи и на черты):

| Улика | Δ log-odds |
|---|---|
| Видел убийство | **+6.4** |
| Видел, как лез в вент | **+5.2** |
| Был наедине с жертвой перед смертью | +1.15 |
| Был в комнате убийства | +1.35 |
| Был рядом с местом убийства | +0.42 |
| Противоречие в алиби | +1.25 × `ContradictionSense` |
| Сам нашёл тело | +0.12…+0.75 (зависит от доверчивости) |
| Выгораживал изгнанного предателя | +0.85 |
| Долго никем не наблюдался | до +0.8 × `Caution` |
| Пропал во время саботажа | +0.16 × `Caution` |
| Был далеко от места убийства | −0.55 |
| Алиби подтверждено | −1.05 |
| Был со мной | −0.09 за наблюдение |
| Замечен на визуальном задании | **−2.6** |

Сверху добавляется шум `±MistakeChance × 1.5` — источник человеческих ошибок.
Самая весомая улика запоминается отдельно (`TopReason`) и потом дословно звучит в чате:
«он крутился возле Реактора», «его слова не сходятся», «я видел, как он лез в вентиляцию».

Подозрение **постоянно меняется**: пересчёт идёт на каждом медленном тике и после
каждой услышанной реплики.

## 6. Алиби и противоречия (`AlibiBoard.cs`)

Каждая фраза «я был в X» / «я видел Y в X» становится `AlibiClaim`. У каждого агента
**своя** доска, потому что «похоже на ложь» зависит от того, что помнит именно он.
На каждое заявление запускаются три проверки:

1. **Против собственной памяти.** Если я помню его в Реакторе, а он говорит про
   Лабораторию — противоречие, сила ∝ уверенность × расстояние между комнатами ×
   `ContradictionSense`. Совпало — наоборот, подтверждение.
2. **Против истории названного напарника.** «Я был с Синим в Лаборатории» ↔ Синий сказал
   «я был в Реакторе». Кто именно врёт — неизвестно, поэтому подозрение растёт у обоих,
   у автора конкретного заявления сильнее.
3. **Против показаний третьих лиц.** Если двое уже поместили его в разные отсеки.

Пойманная ложь переживает собрание (сила уменьшается вдвое), а свежее противоречие
агент выносит в чат репликой `Contradict` — если ещё не выносил.

## 7. Дискуссия (`DebateDirector.cs`, `DialogueBank.cs`)

Собрание — это аукцион реплик. Каждый живой NPC предлагает `SpeechAct`
(интент + конкретная улика + приоритет), директор берёт самого «срочного» с учётом
`SpeakUrgency`, рендерит фразу и раздаёт её всем — после чего доски алиби, доверие и
подозрения пересчитываются.

Приоритеты (сверху вниз):

```
3.4  «ВЕНТ!»                     твёрдая улика
3.3  обвинение по увиденному убийству
2.35 ответ на прямой вопрос
2.25 оправдание / перевод стрелок (у предателя)
1.85 разоблачение противоречия
1.45 собственное алиби
1.15+ обвинение по модели подозрений (порог зависит от Caution)
1.05 поручиться за того, кого можешь очистить
0.85 вопрос молчуну
0.6  заметка про саботаж
0.42 согласие / сомнение
—    молчание
```

Тон реплики выбирается по характеру (спокойный, агрессивный, дружелюбный,
параноидальный, холодный), слоты подставляются из реальных данных: цвет, отсек, улика.
Низкая уверенность добавляет смягчения («не уверен, но…»).

Игрок тоже участвует: его сообщение разбирается простым парсером — упоминание цвета,
названия отсека и ключевых слов («вент», «предатель», «я был», «подтверждаю», «скип») —
и попадает в те же механизмы, что и реплики ботов.

## 8. Голосование (`NpcBrain.DecideVote`)

Экипаж:
1. есть твёрдая улика → голос за неё, что бы ни думала комната;
2. иначе смотрит на складывающееся большинство и с вероятностью `BandwagonBias`
   присоединяется (конформист почти всегда, ветеран почти никогда);
3. иначе сравнивает лучшую вероятность с порогом `0.45…0.72` (зависит от `Caution`) —
   не дотянуло, значит **скип**;
4. с вероятностью `MistakeChance × 0.55` голосует за второго-третьего в списке — так
   рождаются человеческие ошибки.

Предатель:
* если лидер голосования — он сам или его уже обвиняют двое, срочно переводит стрелки;
* если вот-вот выкинут напарника и операция это переживёт — может **сдать напарника**,
  чтобы купить доверие;
* иначе подхватывает волну против мирного;
* волны нет — выбирает самого опасного мирного (умный + убедительный + тот, кто его
  обвинял). Живой игрок считается опасным по умолчанию.

Решение фиксируется, но с вероятностью 25 % пересматривается — отсюда смена мнения
в последний момент.

## 9. Поведение вне собраний

**Экипаж** (`CrewPlanner`) сравнивает утилиты: чинить саботаж (критический — почти
всегда), идти к ближайшему заданию, держаться рядом с тем, кому доверяет (сильнее при
выключенном свете и после убийства), **специально пасти главного подозреваемого**
(если хватает стратегии и смелости), проверить камеры, заглянуть в админ-карту,
патрулировать. Найдя тело — докладывает; поймав кого-то на венте — может сорваться на
экстренный сбор.

**Предатель** (`ImpostorPlanner`) оценивает каждую жертву:

```
utility = близость + изолированность + качество отхода (вент)
        + бонус за темноту/глушение связи
        − риск от невидимых мне игроков, которых я недавно видел рядом
        − риск камеры (учитывая, горит ли её лампочка)
        − собственный «уровень тепла»
        + бонус, если рядом есть кого подставить
```

Если хоть один **видимый** мирный может видеть цель — убийство отменяется. После
убийства: либо уход в вентиляцию с прыжками по сети, либо демонстративный уход в
дальний отсек. Саботаж выбирается по выгоде: свет — под убийство, критический — чтобы
разорвать группу или сбить прогресс заданий (вес растёт вместе с прогрессом экипажа),
двери — чтобы отрезать свидетеля.

Фейковые задания выбираются как настоящие, но визуальные обходятся стороной — вставать
у медсканера на глазах у экипажа предатель не станет.

## 10. Как настраивать

* Веса улик — `SuspicionModel.Evaluate`.
* Пороги обвинения и голосования — `NpcBrain.ProposeSpeech` / `DecideVote`.
* Характеры и архетипы — `AgentPersonality.Generate`.
* Фразы — `DialogueBank` (шаблоны сгруппированы по интенту и тону).
* Утилиты поведения — `CrewPlanner.Plan` / `ImpostorPlanner.Plan`.
* Темп дискуссии — `DebateDirector.TickConversation`.

Ни один из этих файлов не знает про UI, сеть или рендер — менять их можно безопасно.
