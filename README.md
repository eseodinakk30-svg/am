# NEBULA NINE

Социальный детектив на космической станции N-9 в духе Among Us — с собственной вселенной,
своей картой, своим арт-стилем и **главным отличием: NPC, которые играют как живые люди**.

Проект — полноценная игра на Unity: работающий игровой цикл, 38 заданий, саботажи,
собрания с настоящими дискуссиями, голосование, призраки, сетевой мультиплеер и
мобильное управление. Никаких заглушек — всё, что перечислено ниже, реально работает.

---

## Быстрый старт

1. Установи **Unity 2022.3 LTS** (проект помечен как `2022.3.62f1`; любая версия 2022.3.x подойдёт).
   Для Android-сборки добавь модуль **Android Build Support** (SDK/NDK/JDK).
2. Открой папку проекта через Unity Hub → *Add* → выбери корень репозитория.
3. Первый импорт подтянет **URP 14** и запустит автонастройку
   (`Assets/Editor/NebulaProjectSetup.cs`): создаст 4 пресета качества, назначит пайплайн,
   настроит Android-параметры и пропишет сцену в Build Settings.
4. Открой `Assets/Scenes/Boot.unity` и нажми **Play**.

> Сцена намеренно пустая: весь мир (станция, персонажи, интерфейс, звук) строится из кода
> в `Assets/Scripts/Core/Bootstrap.cs`. Поэтому в репозитории нет ни одного бинарного ассета,
> проект открывается в любой установке Unity и не «ломается» на чужой машине.

Если автонастройка почему-то не отработала: меню **Nebula Nine → Setup Project**.

### Сборка APK

**С компьютера:** меню **Nebula Nine → Build Android (APK)** (или AAB), либо из консоли:

```
Unity -batchmode -quit -projectPath . -executeMethod Nebula.EditorTools.NebulaBuild.AndroidApk
```

**Без компьютера, прямо с телефона:** в репозитории настроены GitHub Actions —
сборка идёт в облаке, готовый APK попадает в Releases. Нужны только два
секрета репозитория, `UNITY_EMAIL` и `UNITY_PASSWORD`; файл лицензии не нужен.
Пошаговая инструкция: [`docs/BUILD.md`](docs/BUILD.md).

## Управление

| Действие | Мобильные | ПК (редактор) |
|---|---|---|
| Движение | плавающий стик в левой половине экрана | WASD / стрелки |
| Действие / задание / починка | кнопка **ДЕЙСТВИЕ** (удерживать для ремонта) | `E` |
| Убить | кнопка **УБИТЬ** | `Q` |
| Доложить о теле | кнопка **ДОКЛАД** | `R` |
| Вентиляция | кнопка **ВЕНТ** | `F` |
| Саботаж / карта | кнопки **САБОТАЖ** / **КАРТА** | те же кнопки мышью |

Интерфейс адаптирован под landscape, учитывает вырезы экрана (safe area) и умеет
переключаться в левосторонний режим.

## Что в игре

### Игровой цикл
Лобби → раздача ролей → раунд → задания/убийства/саботажи → обнаружение тела или
экстренный сбор → обсуждение → голосование → изгнание → следующий раунд → победа.

* 4–15 участников, 1–3 предателя;
* победа экипажа: все задания выполнены **или** все предатели изгнаны;
* победа предателей: паритет по численности **или** невыполненный критический саботаж;
* призраки: свободно летают, видят всё, продолжают выполнять задания, не влияют на живых.

### Карта: станция N-9
Две палубы, 21 зона, ~60 источников света, 15 вентиляционных люков в 5 сетях, 2 лифта,
4 камеры наблюдения, админ-стол, закрываемые двери и несколько альтернативных маршрутов.

Верхняя палуба: Реактор, Медотсек, Лаборатория, Оранжерея, Связь, Командный центр,
Пост наблюдения, Столовая, Жилой сектор, Обсерватория, Электрощитовая, Склад,
Двигательный отсек, Грузовой шлюз, Жизнеобеспечение + два кольцевых коридора и
четыре вертикальных прохода.
Нижняя палуба: Трюм, Серверная, Водоочистка, Холодильная установка, Технический уровень,
Ангар дронов.

Вся геометрия, коллайдеры, навигационная сетка и линия видимости выводятся из одного
описания в `StationLayout.cs` — карту можно перекроить, не трогая остальной код.

### Задания — 38 штук, 19 различных механик
Провода, кодовый замок, калибровка ползунками, сортировка груза, очистка фильтра
перетаскиванием, наведение прицела, стабилизация давления, вентили, Simon-says,
выравнивание сетки, весы, трассировка шва, подсчёт контейнеров, настройка частоты по
осциллографу, память-пары, спектр по RGB, разводка труб, карта-пропуск, удержание
заряда, передача данных…

Типы: общие, короткие, длинные, **многоэтапные** (два разных отсека) и **визуальные**
(медсканер, щиты, отстрел астероидов, сброс мусора) — их видно со стороны, и это
единственное железное доказательство невиновности.

### Предатели и саботажи
Kill (с задержкой), Vent (перемещение по сети люков), Sabotage, закрытие дверей,
фейковые задания. Саботажи: свет, реактор, кислород, связь, двигатели, охлаждение, двери —
с тремя схемами починки (одна панель / две одновременно / две в любом порядке).

### Сеть
Собственный UDP-транспорт без внешних пакетов: создание комнаты, 6-символьный код,
автопоиск комнат в локальной сети, приватные/публичные матчи, переподключение по токену,
добивание пустых слотов NPC, а при обрыве связи место игрока подхватывает бот.
Хост авторитетен: клиент **просит** убить/доложить/проголосовать/сдать задание, а хост
проверяет дистанцию, кулдаун и фазу — поэтому «наколдовать» результат с клиента нельзя.

## Главное: искусственный интеллект

Подробное описание — в [`docs/AI.md`](docs/AI.md). Коротко: NPC **не ходят по записанным
маршрутам и не выбирают подозреваемого случайно**. Каждый бот проходит цикл

```
наблюдать → запомнить → оценить → построить гипотезу → обсудить → усомниться → решить
```

* **Личность** — 13 черт и 10 архетипов (аналитик, заводила, добряк, следователь,
  манипулятор, параноик, конформист, работяга, ветеран, болтун). Черты влияют на
  дальность обзора, срок памяти, вес улик, охоту говорить, качество лжи и склонность
  идти за большинством.
* **Память** — эпизодические записи с затуханием уверенности: кого видел, кто куда вошёл,
  кто был один, где нашли тело, кто кого обвинял, кто как голосовал.
* **Восприятие** — единственная точка, где мир превращается в знание. Тот же вызов
  `MatchManager.CanSee`, что и для рендера игрока: дистанция, линия видимости по сетке,
  свет, вентиляция. Роль игрока боту недоступна в принципе.
* **Подозрения** — накопление улик в лог-шансах (а не «рандом»): увидел убийство +6.4,
  увидел вент +5.2, был наедине с жертвой +1.15, противоречие в алиби +1.25,
  подтверждение алиби −1.05, визуальное задание −2.6, и так далее — всё умножается на
  уверенность записи и черты характера.
* **Алиби** — заявления сверяются с личной памятью, со словами названного напарника и с
  показаниями третьих лиц; несостыковки превращаются в публичные обвинения.
* **Диалоги** — реплики собираются из интентов (обвинить, оправдаться, поручиться,
  спросить, ответить, потребовать доказательства, поймать на противоречии, передумать,
  согласиться, усомниться, перевести стрелки, промолчать) с подстановкой конкретной
  улики. По логу собрания можно восстановить, что именно каждый бот думает и почему.
* **Предатель-NPC** — оценивает окно для убийства (свидетели, камеры, пути отхода,
  собственный «уровень тепла»), выбирает саботаж по выгоде, врёт дозированно (смешивая
  правду с ложью), подставляет удобного кандидата, а при провале напарника может сдать
  его ради доверия.
* **Сложность** Easy → Master сдвигает «навыковые» черты, но даже на Master остаётся
  реальный шанс ошибки — бота можно переиграть.

Система AI изолирована в `Assets/Scripts/AI/` и не знает про UI и сеть: интеллект NPC
можно улучшать отдельно от остальной игры.

## Структура проекта

```
Assets/
  Editor/           автонастройка проекта, сборка APK/AAB
  Scenes/Boot.unity пустая стартовая сцена
  Scripts/
    Core/           перечисления, настройки, состояние игрока, шина событий, Bootstrap
    Fx/             процедурные материалы, меши, спрайты, звёздное небо
    Map/            описание станции, сетка навигации + LOS, генерация геометрии,
                    двери, вентиляция, лифты, камеры, свет
    Characters/     процедурная модель персонажа, косметика, 12 анимаций, motor, тело
    Tasks/          модель заданий, каталог из 38 штук, 19 мини-игр, консоли в мире
    Gameplay/       MatchManager (фазы), саботажи, ввод игрока, камера, видимость,
                    пресеты качества, оптимизация
    AI/             личность, память, восприятие, подозрения, алиби, диалоги,
                    дебаты, планировщики экипажа и предателя, навигация, NpcBrain
    UI/             UIKit, HUD, джойстик, миникарта, собрание, меню, модалки
    Net/            протокол, UDP-транспорт, мост между сетью и игрой
    Audio/          процедурный банк эффектов, адаптивная музыка
```

## Графика и производительность

URP, линейное цветовое пространство, 4 пресета (Low/Medium/High/Ultra) с разным
render scale, MSAA, тенями и лимитом дополнительных источников света.
Оптимизации: слияние геометрии станции в несколько мешей, GPU instancing и SRP Batcher,
слияние коллайдеров стен, куллинг дальних источников света, тайм-слайсинг «тяжёлого»
мышления NPC (несколько агентов за кадр), пулы объектов и списков, сжатие текстур ASTC,
IL2CPP + ARM64, автоснижение качества при просадке FPS.

Названия, персонажи, карта, интерфейс, музыка, звуки, тексты и визуальный стиль созданы
для этого проекта. Совпадает только жанровая механика социальной дедукции.
