# Браузерная версия Nebula Nine

`nebula-nine.html` — самодостаточная веб-сборка игры: один файл, никаких ассетов,
никакой установки. Открывается на телефоне и сразу играется.

Это порт игрового ядра из Unity-проекта: та же станция N-9, та же навигационная
сетка с A* и линией видимости, и **та же система NPC** — 13 черт личности,
10 архетипов, эпизодическая память с затуханием, фильтр восприятия, накопление
улик в лог-шансах, граф алиби с поиском противоречий, аукцион реплик и стратегия
голосования с бандвагоном.

## Что вошло

* карта: 15 отсеков, два кольцевых коридора, четыре вертикальных прохода,
  13 вентиляционных люков в 4 сетях;
* 22 задания на 12 разных механиках, включая визуальные;
* аварии: свет, связь, реактор, кислород, блокировка дверей;
* убийства, вентиляция, доклад о теле, экстренный сбор, призраки;
* собрание: сетка игроков, живой чат NPC, голосование, изгнание;
* сложность Easy → Master, 8/10/12/15 участников, 1–3 предателя.

## Чего нет по сравнению с Unity-версией

Нижняя палуба и лифты, камеры наблюдения, админ-стол, сетевой мультиплеер,
кастомизация персонажа и 3D-графика. Всё это осталось в Unity-проекте.

## Проверка

Логика прогонялась вхолостую в Node: 24 полных матча подряд без единого
исключения, средне 3.3 собрания за партию, исход 12/12 между экипажем и
предателями.

```
node --check   # синтаксис
node /tmp/sim.js  # headless-симуляция матчей (см. историю разработки)
```
